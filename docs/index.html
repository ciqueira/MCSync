File transfer control for macOS

MCSync

MCSync is a native macOS application for controlled, user-initiated file transfers between local storage and Google Drive. It supports local-to-local, local-to-Drive, and Drive-to-local operations; analyzes selected content; queues copy and update operations; resumes interrupted transfers; and verifies completed work.

Download beta Usage guide

Apple Silicon · macOS 14.6 or later · rclone included

Operation controls

Transfer analysis, destination structure, and integrity verification.

Transfer analysis

Calculates eligible data and compares it with available destination space before queueing.

Copy and update

Runs local-to-local, local-to-Drive, and Drive-to-local operations with a selectable destination structure.

Integrity verification

Records completion statistics and applies the selected verification method when supported by the endpoints.

Data handling

Files move directly between the selected storage locations.

MCSync requests either read-only or read-and-write Google Drive access, according to the option you select. OAuth tokens are stored locally in an encrypted rclone configuration. MCSync does not upload files, previews, metadata, or credentials to MC or Nexus servers.
