# MCSync

Transfira projetos entre SSDs e Google Drive com análise de espaço, retomada e
verificação de integridade.

O MCSync foi criado para tornar cópias grandes mais simples de acompanhar e
mais fáceis de conferir ao final.

## Guia rápido

Consulte o [Guia rápido de uso](GUIA-RAPIDO.md) para conhecer o fluxo
principal e os controles do aplicativo.

> O MCSync está em fase beta. Utilize cópias de arquivos não críticos durante
> os testes e mantenha a origem até confirmar o resultado.
